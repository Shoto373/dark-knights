## Спринт 4: ИИ врагов и Темница гоблинов [ВЫПОЛНЕН]
- [x] Компоненты `State.gd` и `StateMachine.gd` (idle, chase, attack)
- [x] Ресурс `EnemyData.gd` и 4 типа гоблинов:
  - **Гоблин-рубака** (`goblin_slasher.tres`): ближний бой, быстрый выпад.
  - **Гоблин-лучник** (`goblin_archer.tres`): держит дистанцию, выпускает стрелы.
  - **Гоблин-шаман** (`goblin_shaman.tres`): лечит раненых союзников на 20 HP, держится позади.
  - **Гоблин-громила** (`goblin_brute.tres`): элитный враг, 120 HP, 2 брони, сильный урон с отталкиванием.
- [x] Базовый класс врагов `EnemyBase.tscn` с поиском игрока, хитбоксами и хуртбоксами
- [x] Спавн волн врагов через `WaveSpawner.gd` с расчётом бюджета сложности комнаты
- [x] Ресурс `BossData.gd` и босс **«Вождь гоблинов»** (`GoblinBoss.tscn`):
  - Двухфазный бой (порог 50% HP)
  - Фаза 1: ближний круговой взмах, бросок топора
  - Фаза 2: ярость (+35% скорости, +30% урона, screen shake), призыв 2 гоблинов-подкрепления, рывок с тараном
  - Полоска здоровья босса в `HUD.tscn`
  - Портал перехода в следующий биом после победы над боссом
- [x] GUT-тесты: 32 теста, 1657 проверок (ИИ, переходы StateMachine, лечение шамана, фаза 2 босса, спавнер волн)
