# Game Design Document: «Путь в Чистилище»

## 1. Обзор
- **Жанр:** 2D Top-Down Action Roguelite в реальном времени.
- **Целевая платформа:** Desktop (Windows, Linux).
- **Движок:** Godot 4 (GDScript 2.0).
- **Визуальный стиль:** 2D Pixel-art (1280x720, nearest filter, stretch mode canvas_items).

## 2. Основной игровой цикл (Core Loop)
1. **Хаб:** выбор героя, распределение очков мета-прогрессии (души), выбор доступных путей.
2. **Забег (Run):**
   - Переход по комнатам с процедурной генерацией на основе seed.
   - Сражения с волнами врагов, уклонения, тактическое позиционирование.
   - Сбор лута: золото, здоровье, пассивные и активные артефакты, ключи.
   - Торговцы, сундуки, секретные комнаты.
   - Сражение с боссом этажа/биома.
   - Выбор благословения после победы над боссом.
3. **Граф биомов и развилки:**
   - 0: Хаб
   - 1: Темница гоблинов (Босс: Вождь гоблинов)
   - 2: Ущелье троллей (Босс: Король троллей)
   - 3: Замок Рыцаря-скелета (Босс: Рыцарь-скелет)
   - 4: Развилка: Мир холода (Король-лич) ИЛИ Мир огня (Дракон)
   - 5: Чистилище (Финальный босс, учитывающий выбранную ветку)
4. **Смерть / Победа:**
   - Потеря временных ресурсов забега.
   - Сохранение мета-валюты (души).
   - Возврат в Хаб для разблокировок и улучшений.

## 3. Боевая система
- Движение: 8 направлений с плавным ускорением/трением.
- Защита: Dash (рывок) с кадрами неуязвимости (i-frames).
- Атака: оружие ближнего и дальнего боя, 2 активные классовые способности.
- Расчёт урона:
  `damage = max(1, round(B * (1 + M) * C - A))`
  - $B$: базовый урон.
  - $M$: сумма модификаторов урона (+%).
  - $C$: крит-множитель (1 или `crit_multiplier`).
  - $A$: броня цели.
- Hit-stop: кратковременная пауза (50 мс) и Screen Shake при сочных попаданиях.

## 4. Слои физики и коллизий (2D Physics Layers)
- Слой 1: `world` (стены, препятствия, окружение)
- Слой 2: `player` (тело игрока)
- Слой 3: `enemies` (тела врагов)
- Слой 4: `player_hitbox` (атаки игрока)
- Слой 5: `enemy_hitbox` (атаки врагов)
- Слой 6: `pickups` (подбираемые предметы, сундуки)

## 5. Классы героев
1. **Воин:** высокая живучесть, ближний бой, щитовой блок, рывок с ударом.
2. **Маг:** высокий урон, дальний бой, огненный шар (AoE), телепортация.
3. **Следопыт:** лук, ловушки, веерный залп стрел.
