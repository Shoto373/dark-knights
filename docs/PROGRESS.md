- [x] Hit-stop эффект (~50 мс)
- [x] GUT-тесты: 19 тестов, 50 проверок

## Спринт 2: Герои и хаб [ВЫПОЛНЕН]
- [x] Ресурсы `HeroData` и `AbilityData` (Data-driven архитектура)
- [x] 3 полноценных героя (.tres):
  - **Воин** (`warrior.tres`): ближний бой, щитовой блок (buff), рывок-удар (dash slam).
  - **Маг** (`mage.tres`): снаряды, огненный шар (AoE), телепортация.
  - **Следопыт** (`ranger.tres`): лук, шипованная ловушка, веерный залп из 5 стрел (разблокировка за души).
- [x] Поддержка дальних атак снарядами (`Projectile.tscn`) и взрывов по площади (`AreaOfEffect.tscn`)
- [x] Сцена хаба (`Hub.tscn`):
  - Пьедесталы выбора героев (`HeroPedestal.tscn`) с интерактивным переключением по клавише `F`
  - Портал «Начать путь» (`Portal.tscn`) со стартом забега в `GameState`
  - Разблокировка за души в `MetaProgress`
- [x] Игрок dynamic builder: единая сцена `Player.tscn` автоматически пересобирается под выбранный `HeroData` (статы, цвет, атака, способности)
- [x] HUD: отображение имени героя, душ, кулдаунов способностей Q и E
- [x] GUT-тесты: 23 теста, 80 проверок (включая проверку добавления кастомного героя без правки кода)
