# Путь в Чистилище (Dark Knights)

2D Top-Down Action Roguelite в реальном времени, разработанный на **Godot 4** (GDScript 2.0).

## 🎮 Концепция
Игрок начинает свой путь в Хабе, выбирает героя и отправляется через опасный граф биомов:
- **0. Хаб** (выбор героя, мета-прогресс, старт забега)
- **1. Темница гоблинов** (Босс: Вождь гоблинов)
- **2. Ущелье троллей** (Босс: Король троллей)
- **3. Замок Рыцаря-скелета** (Босс: Рыцарь-скелет)
- **4. Развилка:**
  - **4a. Мир холода** (Босс: Король-лич)
  - **4b. Мир огня** (Босс: Дракон)
- **5. Чистилище** (Финальный биом и босс)

## 🛠 Архитектура
- **Data-Driven:** Герои, враги, предметы, биомы и граф мира описываются через `Resource` (.tres).
- **Композиция:** `HealthComponent`, `HitboxComponent`, `HurtboxComponent`, `MovementComponent`, `StateMachine`.
- **Autoload-синглтоны:**
  - `EventBus` — глобальная шина событий
  - `GameState` — состояние текущего забега
  - `MetaProgress` — постоянный прогресс игрока
  - `SaveManager` — система сохранений в `user://`
  - `AudioManager` — управление звуками и музыкой
  - `SceneRouter` — плавные переходы между сценами с fade-эффектом
- **Детерминизм:** процедурная генерация комнат и этажей детерминирована через seed.
- **Тестирование:** GUT (Godot Unit Test) тесты в папке `res://tests/`.

## 🚀 Запуск и тестирование
- **Открыть в редакторе Godot:** запустить Godot 4 и открыть папку проекта.
- **Запуск тестов GUT:**
  ```bash
  godot -d -s --headless addons/gut/gut_cmdln.gd -gdir=res://tests -gexit
  ```
- **Запуск игры:**
  ```bash
  godot
  ```
